How to edit the questions
  1. Pick a file below, or open deep-cut/prompts/ on GitHub, and tap the pencil to edit it.
  2. Change, add or delete prompts using the format below, then tap Commit changes.
  3. GitHub Pages republishes in a minute or two. Reload this page to check for mistakes, then the game picks up the new bank.
## Movies                       ← category for the prompts below
# Name a Pixar movie             ← a new prompt
Toy Story                        ← answers, most common first
Finding Nemo
Monsters, Inc. | monsters inc    ← | adds another spelling that counts
*Luca                            ← * marks the Mother Lode (optional)

# Name a Friends character {names}   ← first or last name alone counts
Each prompt needs at least 5 answers. Without a *, the game picks a Mother Lode about 70% of the way down the list. Prompt lines need "#" followed by a space, so an answer like #MeToo stays an answer. To add a new file, also add its name to prompts/_files.txt. The full guide is in prompts/README.md.
